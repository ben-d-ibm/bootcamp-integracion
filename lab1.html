🏗️ Ambiente local y FlowService

Configurá un entorno de integración híbrida real: PostgreSQL on-premise en Docker, Edge Runtime en la misma red y el FlowService getClientInfo que consulta el saldo de los clientes.

En este lab

Paso 1 — Levantar la BD Paso 2 — Verificar datos Paso 3 — Edge Runtime Paso 4 — Proyecto IWHI Paso 5 — FlowService
5.1 Crear y asociar Runtime 5.2 Configurar cuenta DB 5.3 Configurar Query 5.4 Pipeline y Test
1

Levantar la base de datos

Corre el siguiente comando según tu entorno. Esto levantará un contenedor con PostgreSQL y ejecutará automáticamente los scripts de inicialización que crearán la tabla clientes y la llenarán con 30 registros dummy.

Docker

docker compose up -d

Podman

podman-compose up -d
⏱️ Primera vez: descarga la imagen (~200 MB). Esperá unos segundos a que el healthcheck de PostgreSQL sea healthy antes de continuar.
2

Verificar los datos de conexión y la carga de datos

Para verificar que los datos se cargaron correctamente, tenés dos alternativas:

Alternativa A — desde un cliente SQL (pgAdmin, DBeaver, etc.)

Conectate usando estos datos:

ParámetroValor
Hostlocalhost
Puerto5432
Base de datosbootcamp_db
Usuariobootcamp_user
Contraseñabootcamp_pass

Alternativa B — desde la consola del contenedor

Entrá a la consola de PostgreSQL:

Docker

docker exec -it bootcamp_postgres psql -U bootcamp_user -d bootcamp_db

Podman

podman exec -it bootcamp_postgres psql -U bootcamp_user -d bootcamp_db

En cualquier caso, ejecutá:

SELECT * FROM clientes;

Deberías ver algo así:

3

Instalar el IWHI Edge Runtime en la misma red

En la consola de IBM Integration, ve a Manage your runtimes desde el home:

Hacé clic en Register runtime y seleccioná Edge runtime:

En el paso de conexión, hacé clic en Generate Credentials para autenticarte con el registry:

Ejecutá los dos comandos que te genera la pantalla. Primero el login:

Docker

docker login -u "<tu-usuario>" -p "<tu-token>" iwhicr.azurecr.io

Podman

podman login -u "<tu-usuario>" -p "<tu-token>" iwhicr.azurecr.io

Y luego el pull de la imagen:

Docker

docker pull iwhicr.azurecr.io/webmethods-edge-runtime:12.0.5.0

Podman

podman pull iwhicr.azurecr.io/webmethods-edge-runtime:12.0.5.0
⏱️ La imagen pesa ~1.5 GB. Puede tardar varios minutos dependiendo de tu conexión.

Se abrirá el wizard de registro. Definí el nombre del runtime (ej: runtime_beetech):

También se mostrará el comando de ejecución (docker run) con los tokens de registro:

El runtime debe correr dentro de la misma red Docker que Postgres (bootcamp_net). Al comando que te entrega IWHI hacele dos ajustes:

  1. Agregá la flag --network bootcamp_net
  2. Cambiá el puerto -p 4430:443 (el 443 puede estar ocupado en tu máquina)

Ejemplo del comando

docker run \
  --network bootcamp_net \
  -p 5555:5555 \
  -p 4430:443 \
  -d \
  ...
⚠️ El token de registro expira en ~15 minutos. Generá el runtime en IWHI, dejá abierta la pantalla y ejecutá el comando inmediatamente.

Una vez registrado, verificá en Manage integration runtimes que figure en estado Ready:

5

Crear el FlowService getClientInfo en IWHI

5.1 — Crear el FlowService y asociar el Runtime

Dentro del proyecto creado (ej: bootcamp_beetech), ve a Flow services y hacé clic en +:

Seleccioná el tipo Deploy Anywhere Flow Service:

En el editor, esquina superior derecha, seleccioná tu Edge Runtime (runtime_beetech):

Hacé clic en Sync para sincronizar:

Asigná el nombre getClientInfo y hacé clic en Save:

5.2 — Configurar la cuenta y conexión a la base de datos

En el canvas, hacé clic en + para agregar el primer paso y buscá el conector Database:

Seleccioná Add Custom Action:

Definí el Action name como getClientInfo y hacé clic para crear la cuenta:

Hacé clic en Add account, definí el nombre postgres_bootcamp, seleccioná tu runtime y hacé clic en Next:

Subí el driver JDBC de PostgreSQL (postgresql-42.7.9.jar disponible en la raíz del repositorio):

En Basic configuration, completá los datos de conexión:

ParámetroValor
DatabasePOSTGRESQL
Transaction typeNO_TRANSACTION
DataSource classorg.postgresql.ds.PGSimpleDataSource
Driver groupJDBC
Server namepostgres
Port number5432
Database namebootcamp_db
Userbootcamp_user
Passwordbootcamp_pass
💡 El host es postgres (no localhost) porque el runtime corre dentro de la misma red Docker que el contenedor de PostgreSQL.

Hacé clic en Next. Se sincronizarán los assets en el Edge Runtime:

Hacé clic en Test connection:

Verificá el mensaje de éxito y hacé clic en Enable:

Confirmá que la cuenta quede habilitada y hacé clic en Done:

Seleccioná la cuenta postgres_bootcamp y hacé clic en Next:

5.3 — Configurar la acción getClientInfo (Query a clientes)

Seleccioná el tipo de operación Select:

En Tables, hacé clic en + para agregar la tabla:

Desplegá bootcamp_db → public y seleccioná clientes:

En Joins, no es necesario agregar joins. Hacé clic en Next:

En Data fields, hacé clic en + para agregar los campos a retornar:

En Condition, configurá el WHERE para filtrar por número de cuenta:

Definí la condición con operador = y placeholder ?:

clientes.numero_cuenta = ?

Revisá el Summary con la SQL generada y hacé clic en Done:

Select clientes.id as id_1, clientes.numero_cuenta as numero_cuenta,
clientes.nombre as nombre_1, clientes.apellido as apellido_1,
clientes.email as email_1, clientes.telefono as telefono_1,
clientes.fecha_nacimiento as fecha_nacimiento_1,
clientes.tipo_cuenta as tipo_cuenta_1, clientes.saldo as saldo_1,
clientes.activo as activo_1, clientes.fecha_alta as fecha_alta_1
from clientes clientes where clientes.numero_cuenta = ?
